# Rapid Modeling

Modeling, in Maya, is the process of creating, generally from starting primitives, more complex shapes

We can sometimes work very rapidly by switching between the Extrude process and the Add Edge Loop tool 

## Extrude

1. Select one or more faces.
2. Press **Ctrl + E**.

This shortcut is the same on Windows and Mac.

## Insert an Edge Loop

1. Hold **Shift** and right-click the mesh.
2. Choose **Insert Edge Loop Tool** from the marking menu.

This method is the same on Windows and Mac.

### Switching Between

Using shortcuts, we can switch between Extrude and Edge Loop

* G — Repeat Last Command\
Example: extrude once, then press G to extrude again.

* Y — Reactivate the Last Tool Used\
Example: use Multi-Cut or Insert Edge Loop, switch away, then press Y to return to that tool.

> **LEARN:** G repeats an action; Y returns to a tool
